=== CNN v2 Architecture (CPU-friendly, target 60%+) ===

3 Convolutional Blocks avec double Conv:
  Bloc 1: Conv32 → Conv32 → MaxPool → Dropout(0.25)
  Bloc 2: Conv64 → Conv64 → MaxPool → Dropout(0.25)
  Bloc 3: Conv128 → Conv128 → MaxPool → Dropout(0.25)

Classification Head:
  Dense(512) → Dense(256) → Dense(7, softmax)

Choix d'architecture:
- Double Conv par bloc : extrait plus de features
- BatchNorm apres chaque Conv : training stable
- Dropout 0.25 conv + 0.5/0.3 head : evite overfitting
- Augmentation: flip + rotation(10) + zoom(0.1)
- Donnees completes (pas de reduction)
- patience=10 EarlyStopping, patience=4 ReduceLR
